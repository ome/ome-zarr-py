# Transformations

This section demonstrates how to work with transformations in OME-ZARR.
Transformations allow to project images into different coordinate systems,
which can be attached to different multiscale images.
This allows co-registered images to be viewed in conjunction with each other,
even if they have different physical coordinate systems.

It is also possible to attach transformations to a single multiscale image,
which allows viewers to choose between different coordinate systems for the same image.
